# Legacy (Organize Files 1.x)

Estes são os scripts originais do **Organize Files** em CustomTkinter (`main.py` em pt-BR e
`main-en.py` em inglês), o projeto que deu origem ao **Orguine**. Ficam aqui apenas para referência
histórica. **Não use**: eles podem sobrescrever arquivos com o mesmo nome e não têm desfazer
(e os ícones antigos da pasta `Design/` não fazem mais parte do projeto).
A versão atual fica no pacote `orguine/` (execute com `python -m orguine`).

These are the original CustomTkinter scripts of *Organize Files*, the project Orguine grew from,
kept for reference only. Use the `orguine` package instead.
